# 🍷 Wine Quality Prediction Using Machine Learning

## 📌 Project Overview
This project uses machine learning to predict wine quality based on its physicochemical properties.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 🤖 Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree

## ⚙️ Project Workflow
1. Data loading and exploration
2. Data preprocessing
3. Feature selection and target preparation
4. Feature scaling using StandardScaler
5. Model training
6. Model evaluation and comparison

## 📊 Results
Model performance is evaluated using appropriate classification metrics.

## 🚀 How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open `wineproject.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.
